# 修正・検証レポート

2026年11月17日。対象はローカルの修正ファイル。公開先への反映は行っていない。

## 実装した流れ

目標・経験・利用時間・音声環境を選ぶ → 教材選択 → 別タブで開く → 元のタブで自己申告の結果と確認方法を残す → 次の行動と理由を表示 → 再読み込み後に再開。

- 教材を開いたこと、振り返ったこと、途中終了を区別した。自動の達成判定・得点取得はない。
- 一覧からすぐ始める操作を維持した。カテゴリからの教材開始も記録し、ホームの振り返りへつながる。
- 「はじめて」に適合確認済みの教材がない場合は、その旨を表示する。
- 音声を使えないときはリスニングを自動おすすめしない。
- 未確認教材は自動おすすめと分け、先生と確認して選ぶ欄に表示する。
- 小目標の再利用、途中終了、次回の行動を実装した。
- ローカル記録は一時保存を初期状態とし、端末保存は選択式にした。消去前に対象を表示する。
- 教材データを一元化し、静的リンクの同期コマンドを追加した。

## 既知の制約

- 小学生が単独で使えると確認できた教材は未整備。対象に合う教材を増やす場合は、先生が内容と操作を事前に確認する。
- 教材カードに「確認中」とある情報は推測で埋めていない。時間の目安も未測定。
- 目標と記録は端末内だけ。記録の同期・バックアップ・複数児童のアカウント分離はない。
- 記録は直近の1件と進行中の1件に限定する。長期の成長分析・教師の閲覧機能はない。
- 目標選択中の未確定入力は記録しない。教材を開いた時点から、再開用の目標と教材を保持する。
- 公開・ホスティング設定は変更していない。
