# 英語の学習ひろば / English Learning Portal

小学生・中学生が英語教材へ進むための、シンプルな入口です。トップは6分野。必要に応じて用途を選び、教材を開きます。目標設定や振り返りを教材利用の条件にしません。

## プレビュー

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/` を開いてください。静的サイトなのでビルド用ライブラリーのインストールは不要です。保存の動作確認はfile URLではなくHTTPで行います。

## 画面

- `index.html`：単語、文法・基本文、読む、聞く、プリント、テスト対策の6つの入口。
- `categories/`：用途の選択。教材が一つなら同じ画面から開始できます。
- `materials/`：複数教材がある分野の短い教材案内。
- `record.html`：任意の振り返り。日付・アプリ・任意の勉強時間（時間・分を選択）・1〜5の満足度、任意の取り組み内容と感想。
- `logs.html`：複数件のログ、今週・今月・半年・1年・すべての期間切り替え、まとめ・時間グラフ・アプリ別集計、日付・アプリの絞り込み、20件ずつの表示、修正・削除。
- `calendar.html`：月曜〜日曜の月間カレンダー。記録日にチェックのスタンプと日別合計時間を表示し、押すとその日のログへ移動。
- `settings.html`：この端末への保存選択、解除、全消去。
- `guide.html`：使い方・共有端末・外部教材についての説明。

## データと再生成

教材情報は `assets/categories.js`、ページ構成は `scripts/build-pages.cjs`、デザインは `assets/styles.css` が元データです。HTMLへ直接加えた修正は、次の再生成で上書きされます。構成を変える場合は生成スクリプト側を編集してください。

```sh
node scripts/build-pages.cjs
node scripts/update-seo.cjs
```

互換コマンド `node scripts/sync-static-links.cjs` でも両方を実行します。教材の紹介・利用条件は実際の機能を確認して更新してください。検索設定は `seo.config.json` で管理し、公開URLとSearch Consoleの確認値を設定できます。

## 検証

```sh
node --check assets/app.js
node --check assets/learning-store.js
node scripts/check-learning-state.cjs
node scripts/check-journal-stats.cjs
python3 scripts/check-static-pages.py
python3 scripts/check-seo.py
```

記録処理はDOMに依存しない `assets/learning-store.js` に分けています。自動チェックは独立したテスト用保存領域を使い、実ユーザーのブラウザー記録を変更しません。

最新の検証結果と画面画像は [qa/simple/verification-report.md](qa/simple/verification-report.md) にあります。

## 記録の扱い

初期状態はsessionStorageによるこのタブの一時記録です。「この端末に記録を残す」を選んだ場合だけlocalStorageへ履歴を保存します。別の端末への同期はありません。共有端末では保存を選ばず、利用後に設定から全消去してください。タブ復元で一時記録が戻る場合もあります。

記録は日付・教材・任意の勉強時間・1〜5の取り組みへの満足度・任意の記述です。勉強時間は合計分数で保存し、時間と分で表示します。時間のない以前のログは「時間未入力」として扱います。教材の成績や正答率ではありません。以前の形式の記録は読み取り用の「以前の記録」として維持し、新しい評価へ換算しません。旧形式の原本は、本人が全消去・永続保存の解除を選ぶまで残します。

本名や学校名などは求めません。ポータルに入力した内容をサーバーへ送る処理、分析サービス、ログイン、教材側との記録同期はありません。配信元のアクセスログや外部教材の保存・通信は別途確認が必要です。

## 公開とGoogle検索

今回はローカルの修正です。公開先・公開設定は変更していません。検索用のページ情報とサイトマップを維持しています。記録・ログ・カレンダー・設定の4ページはnoindexで、サイトマップから除外します。ログの中身はブラウザー内だけで扱います。

公開反映とSearch Consoleの手順は [SEARCH-SETUP.md](SEARCH-SETUP.md) を参照してください。児童生徒の利用観察、学校の実端末、支援技術による確認は別途必要です。

期間集計は `assets/journal-stats.js` に分離しています。今週は月曜〜今日、今月は1日〜今日、半年・1年は今日を含んでさかのぼる期間です。時間未入力は日数・件数に含めますが、時間に加算しません。グラフは日別・月別、全期間が長い場合は年別で表示します。

カレンダーはログ上部の「カレンダーで見る」から開きます。期間集計とは独立して、すべてのアプリの記録を月ごとに表示します。同日に複数記録がある場合は時間を合計し、時間未入力の記録が混ざる日は＊を付けます。旧形式の記録はスタンプ集計に含めません。
